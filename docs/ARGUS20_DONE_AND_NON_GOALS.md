**Дата:** 03.10.2026 · **Правка:** 03 · **Владелец:** Игорь

Изменения 03: из NON_GOALS снят пункт «Локальная GPU / MAIN-PC» решением владельца 03.10.2026 — локальный сборщик контактов Selain на Windows/RTX 4090 ведётся как отдельный исполнитель (`ARGUS20_TZ_SELAIN.md` v3.0) и интегрируется в блоке 6. Остальное без изменений.

## Кто говорит «готово»
Готово говорит только владелец, после того как прокликал интерфейс. Скрипты и тесты служат исполнителю самопроверкой. Исполнитель слово «готово» не использует и пишет «сдан на проверку».

## Критерии рабочей версии (G1–G9)
| # | Критерий | Как проверяет владелец |
|---|---|---|
| G1 | Паспорт: ≥ 4 полей «нашли» с кликабельным источником, остальные — «не нашли» с перечнем проверенного. Ни одного «отсутствует» | Открывает Kortti, кликает источники |
| G2 | Кнопка запуска активна после паспорта без ручного ввода | Нажимает |
| G3 | Прогон стартует ≤ 60 с, годы появляются на экране | Смотрит |
| G4 | ≤ 40 мин на год. Меряется по **последнему опубликованному изданию**: ≥ 60 % от числа его экспонентов — confirmed, у каждой домен и URL, где компания реально названа. Год без опубликованного списка (Verkosto 2027) в G4 не входит: для него проверяется только записанный gap и статус todennäköinen из прошлых лет (C5) | Verkosto 2025 (gold 191): открывает 10 случайных — 10/10. Verkosto 2027: gap виден, confirmed = 0 |
| G5 | 0 компаний из UI-мусора (Image, LinkedIn, Cookie, Evästeet, Hyväksy, Lue lisää…) в любом статусе кроме rejected | Фильтр по названию |
| G6 | ≥ 50 % confirmed имеют ≥ 1 персону с ролью и ≥ 1 канал со статусом ≠ inferred и ≠ stale | Soittolista |
| G7 | Расход на экране = сумма model_call ± 5 % (включая вызовы локальной модели Selain с cost 0) | Сверяет с отчётом |
| G8 | Прогон завершается сам терминальным статусом; через 6 ч нет running без задач | Список прогонов |
| G9 | После деплоя панель открывается снаружи, версия внизу слева новая | Cmd+Shift+R |

Gold для Verkosto 2025 (~191): P ≥ 0.9, R ≥ 0.6. С блока 4 меряется автоматически.

Пилот Selain (8 компаний, `ARGUS20_TZ_SELAIN.md` §13.7) — отдельные пороги сборщика, не критерии G; G6 считается по статусам K3 независимо от того, кто нашёл контакт.
