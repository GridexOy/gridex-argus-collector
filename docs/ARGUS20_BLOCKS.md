## Правила для всех блоков
**Тест-карта и сдача**
- Тест-карта пишется до кода блока и входит в ТЗ блока.
- Шаг сдаётся с версией на экране. Первая проверка всегда: версия и дата новые.
- Сдача блока — отчёт `docs/ARGUS20_BLOCK<N>_REPORT.md` по шаблону ТЗ блока 0 §14 (сборщик: `docs/ARGUS20_COLLECTOR_STAGE<S>_REPORT.md`).

**Версия, ветка, тег**
- Версия: `0.<блок>.<шаг>.<правка>`. Первая сдача шага — `.0`, каждая правка поднимает последнюю цифру.
- Ветка: `block-<N>/step-<M>-<slug>`. Деплой только из `main` после fast-forward; ветка step удаляется после мержа.
- Тег `block-N-start` ставится до начала блока.
- Тег `v0.<N>.<M>` ставится при деплое `0.N.M.0`. Правки тега не получают.
- Сборщик: `stage-S/step-M-<slug>`, `0.<этап>.<шаг>.<правка>`, теги `cv0.S.M`, `stage-S-start`.

**Регрессия**
- Регрессия предыдущих блоков прогоняется в каждом деплое.
- Контрактные тесты сборщика — в CI ARGUS с блока 6.
