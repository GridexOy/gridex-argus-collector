# ARGUS 2.0 — Карта экранов готовой системы

**Дата:** 03.10.2026 · **Правка:** 03. Утверждается владельцем до блока 0.

Изменения 03: Soittolista (блок 6) получает строку состояния Selain, этап и причину неполноты по компании, кнопки «Lähetä Selaimeen» / «Jatka» / «Peruuta», историю наблюдений в карточке контакта; Lokit — префиксы каналов сборщика; добавлены термины. Панель самого сборщика — в `ARGUS20_TZ_SELAIN.md` §5.1.

Экраны и кнопки появляются строго по блокам. Чего нет в коде, того нет на экране, либо оно помечено TYÖN ALLA.

## Общее
**Сайдбар:** ARGUS · Research Operating System · Projektit · Tapahtumat · Liidit · Mallit · Arkisto · Asetukset · FI/EN/SV · версия.

С блока 0 активен только Projektit. Остальные пункты помечены TYÖN ALLA до своего блока:
- Liidit — после блока 5;
- Arkisto — блок 7;
- Tapahtumat, Mallit, Asetukset — после рабочей версии.

**Термины интерфейса (фиксированы):** Projektit, Kortti, Yritykset, Soittolista, Kulut, Lokit, Liidit, Arkisto, Tapahtumat, Mallit, Asetukset, Luo uusi projekti, Kokoa uudelleen, Käynnistä haku, TYÖN ALLA, Selain, Lähetä Selaimeen, Jatka, Peruuta, Nähty viimeksi. Новый термин — сначала здесь, потом в коде.

## 1. Projektit (блок 0–1)
- Заголовок и кнопка «Luo uusi projekti».
- Карточки: название, статус, дата. С блока 3 добавляются счётчики компаний и контактов из одного запроса.
- Клик по карточке открывает страницу проекта (блок 1).
- Четыре состояния: загрузка / пусто / ошибка загрузки / список.

## 2. Luo uusi projekti (блок 0–1)
- **Блок 0:** одно поле — название.
- **Блок 1:** добавляются год (необязательно), URL организатора (необязательно), потолок расхода € (по умолчанию 5).
- «Luo» создаёт проект и открывает его страницу.

## 3. Страница проекта — шапка (блок 1)
← Projektit · название · год · статус · вкладки: Kortti · Yritykset · Soittolista · Kulut · Lokit.

Вкладки без кода неактивны. Kulut неактивна до блока 7.

## 4. Kortti — паспорт (блок 2)
**Строки паспорта:** Järjestäjä · Tapahtumapaikka · Ajankohta · Sykli · Toimiala · Katalogialusta · Näytteilleasettajat vuosittain · Tapahtuman verkkotunnukset.

Каждая строка:
- находится в одном из трёх состояний, с иконкой;
- источник показан ссылкой;
- при «не нашли» раскрывается список проверенного.

**Блок Scout:**
- 4 модели → N подсказок, M проверено;
- строка расхода «Kulut tähän mennessä: €0.42» — сумма `model_call` по проекту, один источник, обновляется вместе с паспортом.

**Кнопки:** «Kokoa uudelleen», «Käynnistä haku» (активна при ≥ 4 «нашли»).

Ошибки провайдеров (например, нет кредитов) видны здесь же.

## 5. Yritykset — компании (блок 3–5)
- **Таблица:** компания · домен · годы (чипы со статусом) · приоритет (3×/2×/1×) · источник (ссылка + иконка снимка) · статус.
- **Фильтры:** год, статус, приоритет, «показать rejected».
- **Клик** открывает карточку компании: алиасы, участия, все источники, люди (блок 6).
- **Сверху** — покрытие по годам, например «142 / 191 (K0 120, K1 22)».
- **С блока 4** добавляется строка P/R против gold, если gold есть.

## 6. Soittolista — люди и каналы (блок 6)
- **Шапка:** строка состояния сборщика из одного запроса: `Selain: ei yhteyttä` / `Selain: yhdistetty · keskeytetty` / `Selain: kerää · N yritystä jonossa` / `Selain: tulosten lähetys epäonnistui` (красным).
- **Таблица** по компаниям с приоритетом: человек · должность · роль · телефон · email · статус канала (K3) · дата · источник.
- **Строка компании** дополнительно: этап Selain (`Odottaa käsittelyä` / `Haetaan sivuja` / `Selain käsittelee` / `Tarvitsee huomiota` / `Valmis` / `Osittain valmis` / `Keskeytetty` / `Epäonnistui`), henkilöt · kanavat · lähteet, причина неполноты (по коду `completion_reason`, через i18n), кнопки «Jatka» и «Peruuta».
- **Кнопка** «Lähetä Selaimeen» — на выбранных компаниях; неактивна для компаний без участия `confirmed`/`strong_historical`.
- **Карточка контакта:** канал · статус · исходное значение · источник (ссылка + иконка снимка) · дата наблюдения · `Nähty viimeksi` · история наблюдений (`muuttunut` / `vahvistettu` / `ei nähty tarkistetussa laajuudessa`).
- **Фильтр:** «только проверенные каналы» (без `inferred` и `stale`).
- **Кнопка** «Vie CSV/XLSX» (блок 7).

Наличие снимка HTML не даёт зелёного статуса полноты; показывается то, что в базе.

## 7. Kulut — расход (блок 7)
По прогону показываются:
- всего €;
- по каналам (включая Selain: локальная модель 0 €, облако по бюджету кампании);
- по моделям;
- yield каналов;
- время по шагам;
- потолок и остаток.

До блока 7 вкладка неактивна; расход виден только строкой на Kortti (блок Scout).

## 8. Lokit (блок 3)
Журнал прогона: шаг, время, результат, ошибки. Только чтение. С блока 6 — записи сборщика с префиксом `http` / `browser` / `extraction` / `delivery` / `model`; без значений контактов и секретов; пакеты с `override_reason` видны здесь.

## 9. Liidit — все компании и люди из всех проектов (после блока 5)
Та же таблица, что Yritykset, без привязки к проекту, с фильтром по выставкам.

## 10. Arkisto (блок 7)
Архивированные проекты, только просмотр.

## Чего нет на экранах до рабочей версии
Карта-граф, чат, Fable, автопилот как переключатель, мониторинг, календарь, EN/SV, настройки, шаблоны, отдельный веб-экран сборщика в ARGUS (панель сборщика живёт на Windows).
